# Wanderly Travel & Tours Website — V20 Complete Multi-page Remake

React/Next.js homepage remake based on the supplied Tourm-style reference screenshots.

## Included
- Sticky responsive header with working routes across all pages
- Multi-page routes: Home, About, Destinations, Services, Activities, Tour Guides, Testimonials, Gallery, Blog, Contact, FAQ, Booking, Terms, and Tour Details
- Dedicated travel-related content layouts for tour listings, blog articles, gallery, guides, reviews, contact/booking forms, FAQ and terms
- Reusable footer on all inner pages with newsletter validation, quick links, contact details, Instagram grid and back-to-top control
- Removed empty `href="#"` placeholders; internal navigation now points to real routes and social icons use external destinations
- Existing header, hero, booking/search panel and previous homepage sections
- Tour categories, destinations, trip planning, popular tours, gallery, statistics, tour guide and testimonial sections
- Screenshot-matched travel brand/logo strip with autoplay, mouse drag and touch swipe
- Screenshot-matched News & Articles section with 3-column desktop layout, autoplay, mouse drag and touch swipe
- Local reference assets extracted from the supplied screenshot for the visible logo/article imagery
- Responsive desktop/tablet/mobile styling

## Run
```bash
npm install
npm run dev
```
